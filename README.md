Strategic Radar Maroc

Prototype académique Streamlit d’intelligence économique multisectorielle.

Déploiement

* Branche : main
* Fichier principal : app.py
* Dépendances : requirements.txt

Données et limites

Toutes les valeurs P1–P5 sont fictives. Les liens institutionnels constituent des points de départ pour rechercher et importer des données officielles. Cette version ne récupère pas automatiquement les données depuis ces sites.

Lancement local

pip install -r requirements.txt
streamlit run app.py
