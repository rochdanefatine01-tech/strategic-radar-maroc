Strategic Radar Maroc

Prototype académique Streamlit d’intelligence économique multisectorielle.

Déploiement

• Branche : main
• Fichier principal : app.py
• Dépendances : requirements.txt

Toutes les valeurs P1–P5 sont fictives. Les liens institutionnels sont des points de départ pour rechercher et importer des données officielles; cette version ne récupère pas automatiquement les données depuis ces sites.

Lancement local : pip install -r requirements.txt puis streamlit run app.py.
